# Блог europartswest.com.ua

Статті — Markdown-файли в `blog/posts/<slug>.md`. HTML генерується скриптом:

```
pip install markdown
python3 tools/build_site.py .
```

Скрипт перебудовує підсторінки, `404.html`, `blog/index.html`, сторінки статей, `sitemap.xml`, `robots.txt`.
Стаття з датою в майбутньому не публікується, доки не настане її дата. `index.html` правиться вручну, крім блоку «Свіжі статті» між `<!-- BLOG:START -->` і `<!-- BLOG:END -->` — його генерує скрипт.

**Деплой:** на хостингу cron кожні 15 хв робить `git pull` у `public_html` (лог: `~/git-autopull.log`). Достатньо запушити в `main` — за ≤15 хв зміни на сайті. API-токени на тарифі Hostpro вимкнені.
`blog/.htaccess` — HTML блогу без кешу (браузер перевіряє свіжість), щоб нові статті одразу було видно.

## Формат статті

```
---
title: Заголовок (до ~70 символів)
date: 2026-11-10
description: 1–2 речення для Google і картки статті (до ~160 символів)
cover: назва-файлу.jpg        # лежить у images/blog/, 1600px по ширині, JPEG
cover_alt: що на фото
cover_jcb: файл.jpg            # необов'язково: жовте фото для теми JCB (інакше images/home/hero-jcb.jpg)
tags: Manitou, JCB
links: to, fuel                # ключі CATS у tools/build_site.py — кнопки в каталог/сервіс
---
Текст статті. `## Підзаголовки`, списки, `> **Порада:** …` — блок-порада.
```

## Правила (контент-план: https://claude.ai/artifact/JatumK6JzcS3oGNrqTrAr6)

- Заголовок — так, як людина пише в Google: питанням («Чому Manitou не заводиться в мороз?», «Як…», «Що…»).
- 600–1000 слів, українською, без вигаданих цифр і без цін.
- **Професійна технічна мова** (вимога власника, 07.11.2026). Пишемо як сервісний інженер, без розмовних слів:
  - олива (моторна, гідравлічна, трансмісійна), оливний фільтр — НЕ «масло», «масляний»; мастило — густе змащення (точки змащення, шприцювання);
  - охолоджувальна рідина (а не «антифриз» як загальна назва), дизельне паливо (не «дизпаливо», «солярка»);
  - «причина — …», «спричиняє», «призводить до» — НЕ «винне», «винуватець»;
  - «запуск/пуск двигуна», «прокручування стартером», «холостий хід», «розряджений акумулятор», «рукав високого тиску», «підтікання»;
  - без жаргону й лапок-сленгу: «троїть», «підсідає», «бадьоро», «балончик», «не мучте», «поворушіть», «сів акумулятор».
- Не приписувати фірмі те, чого вона не заявляла (бренди-аналоги, гарантії, терміни).
- Ключові слова: і «Маніту» кирилицею, і «Manitou»; «сервіс Маніту», «запчастини Маніту», «сервіс JCB» — у тексті природно, хоча б раз.
- Обкладинка — реальні фото техніки з `images/about-us/` (обрізані до 1600px), без чужих логотипів.
- Посилання на потрібну категорію каталогу; у кінці — заклик залишити заявку або зателефонувати.
- Після змін JS/CSS — підняти `V` у `tools/build_site.py` і `?v=` в `index.html`.

## Мова — грамотна українська (обовʼязково)
- «за артикулом / за моделлю», НЕ «по артикулу / по моделі»
- «двигун», НЕ «мотор» (але «моторна олива» — правильно)
- «терміни», «витрати» — НЕ «строки», «затрати»
- «із запчастинами» після приголосного (бригада із запчастинами)
- «кожухи мостів», НЕ «чулки»
